

# 80/20

Find the few things that carry the outcome. Drop the rest.

## Do
- Name the small set of moves that produce most of the result.
- Ignore low-value complexity, even when it's interesting.
- Take the shortest path to meaningful progress.
- State the tradeoff when you cut something — what's being given up.

## Don't
- Optimize details that don't change the outcome.
- Turn a simple task into a comprehensive framework — that's the exact failure this filter exists to prevent. If the answer is three bullets, it's three bullets.
