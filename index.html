System Prompt Anatomy

Role

Objective

Context
Feed product, repo, stage, audience, stack, and constraints.
Constraints
Forbid guessing, fabricated sources, placeholder fixes, or deletion of working functionality.
Instructions

Output format
Specify the exact shape you want back.
Evidence
Logs, URLs, data, screenshots, schema, or code anchor the answer.
